# Online Retail – Data Science Gruppenprojekt

Dieses Projekt wurde im Rahmen des 2. Semesters des Data Science Kurses erstellt.

## Projektbeschreibung

Anhand eines Online-Retail-Transaktionsdatensatzes (UCI / Sakar et al., 2019) werden verschiedene Machine-Learning-Methoden angewendet, um Kundenverhalten zu analysieren und vorherzusagen.

Die Analyse gliedert sich in vier Notebooks:

| Notebook | Inhalt |
|----------|--------|
| 01 – Datenbereinigung & Exploration | Laden, Bereinigen und Explorieren des Rohdatensatzes |
| 02 – Unsupervised Learning | Kundensegmentierung mit K-Means (k=3) |
| 03 – Supervised Classification | High-Value-Customer erkennen (Decision Tree, KNN, Naive Bayes) |
| 04 – Supervised Regression | Kundenumsatz vorhersagen (Linear, Decision Tree, Polynomial) |
